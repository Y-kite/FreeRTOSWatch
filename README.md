# 基于STM32F103C8T6和FreeRTOS的智能手表系统设计
## 1.项目概览
**项目演示:** (待更新)

**功能列表:**
- 时间显示
- 时间设置
- 多级菜单导航
- 闹钟
- 三子棋游戏
- 手电筒
- 音乐
- 温湿度检测

## 2.硬件设计
**各模块引脚:**
|硬件模块|引脚|
|:---:|:---:|
|四个按键|PB11(Akey)、PB10(Bkey)、PB1(Ckey)、PB0(Dkey)|
|无源蜂鸣器(高电平触发)|PA3(闹钟蜂鸣器)、PA8(音乐蜂鸣器)|
|DHT11温湿度传感器|PA2|
|OLED显示屏|PB6、PB7(使用硬件I2C)|

## 3.软件设计
**FreeRTOS任务流程图:**
```mermaid
flowchart TD
  A([时间显示任务
  <挂起除闹钟外其它任务>]) -->|恢复该任务并挂起自己| B(菜单任务)
  A -->|恢复该任务并挂起自己| C(时间设置任务)
  C --> |恢复该任务并挂起自己| A
  B -->|恢复该任务并挂起自己| A
  B -->|恢复该任务并挂起自己| D(温湿度检测任务)
  B -->|恢复该任务并挂起自己| E(音乐任务)
  B -->|恢复该任务并挂起自己| F(手电筒任务)
  B -->|恢复该任务并挂起自己| G(游戏任务)
  B -->|恢复该任务并挂起自己| H(闹钟设置任务)
  D -->|恢复该任务并挂起自己| B
  E -->|恢复该任务并挂起自己| B
  F -->|恢复该任务并挂起自己| B
  G -->|恢复该任务并挂起自己| B
  H -->|恢复该任务并挂起自己| B
  I(闹钟任务
  <优先级较其它任务高>)
```
---
说明：除闹钟任务外所有任务优先级设为一样(我设的18)，闹钟任务优先级高一点(我设的23)
